Política de Privacidade
Como o EstoqueIA coleta, usa e protege suas informações.
💡 Resumo simples

O EstoqueIA não coleta seus dados em servidores externos. Tudo que você registra fica salvo apenas no seu próprio dispositivo. Não temos acesso a essas informações.

📋 1. Quais dados são armazenados

O aplicativo armazena localmente no seu navegador:

  • Produtos: nome, quantidade, preço de custo e venda, consumo diário
  • Histórico de vendas registradas
  • Dados financeiros: gastos mensais e lucros
  • Contatos: nome, cargo e número de WhatsApp
🤖 2. Uso da Inteligência Artificial (Groq)

As mensagens do chat são processadas pela API da Groq, que executa o modelo LLaMA 3.3. As mensagens trafegam via HTTPS de forma segura através de um backend que protege a chave de API.

Não inclua dados pessoais sensíveis (CPF, senhas, dados bancários) nas mensagens. A Groq tem sua própria política em groq.com.

📲 3. WhatsApp

A função de mensagem abre o WhatsApp com texto pré-preenchido. Nenhuma mensagem é enviada automaticamente — você sempre confirma antes. Os números ficam apenas no seu dispositivo.

🔗 4. Compartilhamento de dados

O EstoqueIA não vende, aluga nem compartilha seus dados. Os únicos dados que saem do dispositivo são as mensagens enviadas à API da Groq para processamento da IA.

🛡️ 5. Segurança

Toda comunicação é feita via HTTPS (criptografado). A chave de API fica em variáveis de ambiente seguras no servidor, nunca exposta ao navegador.

⚖️ 6. Seus direitos (LGPD)

Em conformidade com a Lei nº 13.709/2018 (LGPD), você tem direito a:

  • Acessar todos os dados armazenados (visíveis diretamente no app)
  • Corrigir dados incorretos a qualquer momento
  • Excluir todos os dados limpando o localStorage do navegador
  • Exportar seus dados via a função "Planilha"
✏️ 7. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data no topo indica a versão vigente.

Armazenamento de Dados
O EstoqueIA não usa cookies de rastreamento.
🍪 Sem cookies de rastreamento

O EstoqueIA não utiliza cookies de rastreamento, analytics ou publicidade. Não há pixels de rastreamento nem scripts de coleta de comportamento.

💾 localStorage — onde seus dados ficam

Usamos o localStorage do navegador. Os seguintes itens são salvos:

  • estoque_db — lista de produtos cadastrados
  • contatos_db — contatos de WhatsApp
  • gastos_mensais — gastos mensais informados
  • lucros_mensais — lucro do mês atual
  • lucros_mes_anterior — lucro do mês passado
🗑️ Como apagar seus dados
  • Chrome: Configurações → Privacidade → Limpar dados de navegação → Dados de sites
  • Firefox: Configurações → Privacidade → Limpar dados → Conteúdo web em cache
  • Safari: Configurações → Safari → Limpar histórico e dados de sites

⚠️ Limpar os dados apagará permanentemente todos os produtos, vendas e contatos do app.
